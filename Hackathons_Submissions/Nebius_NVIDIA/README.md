## Judge path (short)

1. Open the live app → **Sign in** → **Use demo credentials**.
2. On `/new`, run **live Nemotron demo** (not only the saved sample).
3. Detect (Super) → select a draft → Generate (Ultra) → open research (Tavily + Super).
4. Confirm model id in draft footer / Settings → AI Compute.
