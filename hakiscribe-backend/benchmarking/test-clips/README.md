# Benchmark test clips

Record **5–8 short (under 90s)** consented clips of natural Swahili–English legal speech. Do not use real client data.

Suggested scenarios:

1. Court-hearing snippet (judge + advocate)
2. Client intake (English/Kiswahili mix)
3. Judge dictating a ruling
4. Lawyer voice memo on a matter
5. Clerk reading case number and parties

For each clip:

1. Save audio as `clip_XX.webm` (or update `audio_file` in meta)
2. Hand-write `clip_XX.reference.txt`
3. Fill `clip_XX.meta.json` including `key_terms` (names, amounts, case refs)

All templates below ship **without audio** until you record them locally.
